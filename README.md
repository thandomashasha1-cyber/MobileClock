# MobileClock
Technologies : Java, Android Studio, Android SDK 

Developed a full-featured Android clock application with digital time display, alarms, stopwatch, countdown timer, and notification functionally.
Implemented alarm scheduling, alarm sounds, vibration, snooze controls, and background services.
Added user settings for themes, time formats, vibration preferences, and snooze duration. 
Applied Android lifecycle management, local data storage, permissions, and service-based functionality.
